# 连输统计脚本使用说明

## 脚本功能

本脚本用于分析麻将游戏中的连输情况，主要功能包括：

1. **按天统计输赢**：将每日的游戏结果汇总，计算当日总输赢
2. **识别连输期间**：连续输钱的天数会被识别为一个连输期间
3. **生成详细报告**：输出Markdown格式的统计报告
4. **提供分析建议**：基于历史数据给出金额准备建议

## 使用方法

### 基本用法

```bash
# 全局统计（所有地点）
python losing_streak_analysis.py --db "../backend/data/griffin.db" --output "全局报告.md"

# 指定地点统计
python losing_streak_analysis.py --db "../backend/data/griffin.db" --location "紫竹郡" --output "紫竹郡报告.md"
python losing_streak_analysis.py --db "../backend/data/griffin.db" --location "花漾涧" --output "花漾涧报告.md"
```

### 参数说明

- `--db`：数据库路径（**必须提供**，例如：`../backend/data/griffin.db`）
- `--location`：指定地点名称（可选）
- `--output`：输出Markdown文件路径（**必须提供**）
- `--json`：输出JSON数据文件路径（可选）

### 注意事项

1. **必须参数**：`--db` 和 `--output` 参数必须提供，否则脚本会显示帮助信息并退出
2. **无默认值**：脚本不再使用默认参数，所有必要参数必须显式指定
3. **帮助信息**：使用 `python losing_streak_analysis.py --help` 查看完整使用说明

### 示例

```bash
# 生成紫竹郡的连输报告
python losing_streak_analysis.py --location "紫竹郡" --output "reports/紫竹郡_连输分析.md"

# 生成全局报告并保存JSON数据
python losing_streak_analysis.py --output "reports/全局分析.md" --json "reports/data.json"
```

## 报告内容

生成的Markdown报告包含以下部分：

### 1. 连输记录表
- 按连输天数降序排列
- 显示连输期间、天数、总输金额、日均输额、场次

### 2. 统计分析
- **基本统计**：最少/最多连输金额、平均/中位数金额
- **天数统计**：最短/最长/平均连输天数
- **金额覆盖分析**：50%、75%、90%、95%、99%百分位的日输额
- **建议准备金额**：基于历史数据的风险覆盖建议

## 技术实现

### 数据来源
- 数据库：SQLite (`griffin.db`)
- 主要表：`games`, `player_records`, `players`, `locations`
- 统计逻辑：按玩家ID为"我"的记录进行日级别汇总

### 算法逻辑
1. **日级别汇总**：将同一天的所有游戏记录汇总，计算当日总筹码变化
2. **连输识别**：连续输钱的天数被识别为一个连输期间
3. **统计分析**：计算各种统计指标和百分位数
4. **报告生成**：格式化为易读的Markdown报告

### 代码结构
- `losing_streak_analysis.py`：主脚本文件
- 函数模块化设计，便于维护和扩展
- 支持命令行参数，灵活配置

## 注意事项

1. **数据准确性**：确保数据库中的玩家记录正确标记"我"（`is_me = 1`）
2. **时间范围**：脚本分析所有可用数据，无时间范围限制
3. **金额单位**：报告中的金额单位为游戏筹码
4. **风险提示**：建议金额仅供参考，实际决策需考虑个人风险承受能力

## 扩展建议

1. **时间范围筛选**：可添加`--start-date`和`--end-date`参数
2. **多维度分析**：可扩展分析不同时间段、不同对手组合的连输情况
3. **可视化图表**：可添加生成图表的功能（如折线图、柱状图）
4. **预警功能**：可基于历史模式设置连输预警阈值
