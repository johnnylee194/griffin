# 运势功能设计上下文

> 用于：发给设计 AI（如 Claude Design / Figma AI）参考

---

## 1. 产品定位

**产品名**：Griffin（格里芬）
**功能**：每日运势，专为四川麻将血战到底玩家设计
**核心价值**：八字黄历 + 麻将场景 + 详细推导过程 = 让玩家"信服"的运势参考

**设计理念**：
- 详细推导过程是核心差异化价值——让人"知其然更知其所以然"
- 所有内容围绕打牌场景，不谈婚丧嫁娶
- 专业感（八字/神煞/纳音） + 麻将术语（川麻专用词）

---

**用户**：黎诗佳（Johnny），43岁，成都
**八字**：
- 年柱：丙午（火马）
- 月柱：癸巳（水蛇）
- 日柱：庚辰（金龙）

## 3. 七个维度详情

### 维度1：fortune（今日运势）

**定位**：最核心的维度，给出今日能量总判断，推导过程最详细，字数最多。

**包含内容**：
- 日主分析（庚金是什么意思）
- 得令/失令（月令对日主的影响）
- 坐禄/失禄（日支对日主的补强/削弱）
- 十神分析（偏财/正财/官杀等代表什么）
- 纳音分析（年柱/月柱/日柱/时柱的纳音能量质感）
- 今日叠加（八字 + 今天黄历的叠加效果）

**推导风格**：
1. 先讲"你的八字事实"
2. 再讲"今天的事实"
3. 最后"叠加推导"出结论

**示例结构**：
```
第一步：你的八字事实
你是庚金日主，生在辰月（食神当令），坐辰土印星，地支辰午未一片土。
庚金身弱。土太旺是命局最大问题。

第二步：今天的事实
今日甲辰年 戊辰月 壬辰日
辰月辰日，土气极旺。壬水坐辰，辰是水库，但土太旺把水憋住了。

第三步：叠加推导
你的八字最大问题是土太旺。今天辰月辰日，土更旺。
土旺 → 金被埋 → 牌运迟钝，抓什么都碰壁
但今天有甲木透出。甲木破印，是今天的救星。
```

**结论**：旺/平/弱 + 一句话核心判断

---

### 维度2：betting（投注策略）

**定位**：从 fortune 推导出来的独立结论，告诉用户今天打牌应该大注还是小注。

**推导过程**：
- 能量水平（fortune的旺/平/弱）
- 十神财运型（偏财旺还是正财稳）
- 纳音质感（爆发型还是持续型）
- 麻将连接（运气成分 + 心态 + 资金策略）

**结论**：大注 / 小注 / 观望 + 理由

**示例**：
```
结论：小注
今天是炉中火年柱，不是那种能一把翻盘的能量，
而是持续输出型。运气成分不够，不押太大。
赢了别贪，输了别恋战。
```

---

### 维度3：bestAction（麻将决策）

**定位**：麻将场景下的具体决策建议，5个独立场景。

**5个场景**：

1. **下叫（听牌）决策**：今天适合宽叫（听牌张数多）还是大叫（番数高）

2. **碰 vs 摸**：什么情况下该碰牌，什么情况下该摸新牌

3. **放炮 vs 自摸**：遇到可以胡的牌，是放炮就胡还是贪自摸

4. **对手方位观察**：今天要防哪个方位的人，不怕哪个方位

5. **收官策略**：牌局尾声，乘胜追击还是见好就收

**四川麻将专用术语**（必须用这些词）：
- 下叫 = 听牌
- 宽叫 = 胡牌张数多，容易胡到
- 大叫 = 番数高，胡大番
- 放炮 = 别人打出一张你可以胡
- 自摸 = 自己摸到那张胡
- 碰 = 碰牌，确定的组合
- 摸 = 从牌墙摸新牌，有不确定性

**推导风格**：先讲麻将事实 → 再说八字/能量/运势如何影响这个决策

---

### 维度4：direction（方位）

**定位**：4人座位（东南西北）的策略分析。

**两个层面**：

**层面1：各位置策略**
- 坐在北位怎么打
- 坐在东位怎么打
- 坐在南位怎么打
- 坐在西位怎么打

**层面2：上下家对家克防关系**
- 坐在某位时，上家是谁、下家是谁、对家是谁
- 木克土、土生金、金帮金……各是什么关系
- 对不同方位的对手应该采取什么策略

**示例**（北位）：
```
北位策略：打法可以稍微大胆，有机会冲大番

座次关系：
- 上家 = 东（木气）→ 木被你所制，不防
- 下家 = 西（金气）→ 金帮金，不防
- 对家 = 南（火气）→ 火克你的金，对家要防
```

**四川麻将术语**：用东南西北，不用左边/右边

---

### 维度5：goldenTime（黄金时段）

**定位**：12时辰的运势起伏，给出今天的最佳时段和最差时段。

**数据**：12个时辰，每个时辰包含：
- 时辰名（子/丑/寅/卯/辰/巳/午/未/申/酉/戌/亥）
- 时间段（23-01/01-03/03-05...）
- 五行属性（金/木/水/火/土）
- 星级评分（1-5星，5星最优）
- 麻将打法建议

**示例**：
```
酉时（17-19）│ 金 │ ★★★★★ │ 日主本气，最旺时辰，全力出击
巳时（09-11）│ 火 │ ★☆☆☆☆ │ 火克金，最差时辰，手风不稳，保守
```

**结论**：给出3个最优时段 + 3个最差时段 + 趋势描述

---

### 维度6：conflictWarning（冲煞空亡）

**定位**：今天的警示信息，告诉你哪些地方容易出问题。

**四种破坏性能量**：

1. **冲**：日支和某字相冲，今天能量撕扯不稳定
2. **破**：日支和某字相破，今天有意外消耗
3. **害**：日支和某字相害，今天暗中被压制
4. **空亡**：日柱天干配不到的地支，某些能量是虚的

**推导风格**：每个概念掰开揉碎——是什么 → 为什么是这样 → 对打牌的具体影响

**示例**：
```
辰戌冲：
冲意味着今天的你精力旺盛但状态不稳定，容易心浮气躁。
表现在牌桌上：坐不住，判断比平时容易出错，本来稳赢的牌也可能出岔子。
```

**麻将场景下的具体警示**：
- 今天做大番要谨慎——冲+破让你的状态不稳定
- 大牌做好了下叫之后，最后几张摸牌要格外小心
- 某个时段本来是运气最好的时段，但今天空亡，这些时辰的运气是虚的

---

### 维度7：luckEnhancement（开运清单）

**定位**：今天可以做的具体行动，让八字/五行对自己更有利。不是通用风水，是今天特有的结论。

**三个子类**：

**饮品**
- 宜：菊花茶/绿茶（木气，借甲木之力）
- 忌：红茶/普洱（土气，火上浇油）
- 可选：矿泉水/气泡水

**穿着颜色**
- 宜：绿色/青色（木气，今天当令）
- 忌：白色/银色（金旺，比劫争财）
- 点缀：红色

**饰品**
- 宜：木制手串/翡翠绿松石（木气助财）
- 忌：金属手镯/银饰（金旺争财）

**推导过程**（四步走）：
1. 八字事实（日主旺衰喜忌）
2. 今天事实（五行结构，哪股气最旺）
3. 叠加推导（今天的核心问题 + 救星是什么）
4. 三类清单（饮品/穿着/饰品）

**不纳入的条目**：
- 数字（麻将场景无法结合八字）
- 左手/右手摸牌（摸牌顺序固定）
- 上厕所时机（通用风水，无八字推导）
- 选座位（川麻是抽签决定）

## 4. 可用的基础数据

**八字数据**（lunisolar 计算，<1ms）：
- 八字四柱（年/月/日/时干支）
- 纳音五行（剑锋金、山头火……）
- 十神（比肩、劫财、正官、七杀……）
- 神煞（文昌贵人、驿马星……）
- 日支冲/破/害/空亡

**每日黄历数据**（lunisolar thegods 插件）：
- 宜/忌（宜打牌、忌赌大……）
- 吉神方位（财神正东、喜神正南……）
- 凶煞方位
- 黄道黑道日

**时间相关**：
- 当前时辰（12时辰循环）
- 今日日期

## 5. 设计约束

- **平台**：移动端 PWA（手机浏览器为主）
- **语言**：中文，繁体/简体均可
- **美学方向**：待设计 AI 提供建议，以下为参考方向
  - 传统感但不老气（八字/黄历是传统元素）
  - 专业感（让人相信这个解读是有根据的）
  - 麻将场景的轻松感（不是算命先生的严肃，而是牌桌上的趣味）
- **内容密度**：7个维度，每个维度有大量推导过程文本
- **交互特点**：
  - 推导过程默认展开还是折叠？
  - 7个维度的优先级如何区分？
  - 用户在牌桌上快速扫信息的场景需求
