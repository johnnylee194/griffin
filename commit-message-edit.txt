feat: 添加自定义时间和编辑对局功能

主要改动：

1. 后端 API 改动
   - POST/PUT /games：支持 createdAt 参数，允许自定义对局时间
   - 创建对局时可指定时间，更新对局时可修改时间
   - 时间格式：ISO 8601（不带时区标识，本地时间）

2. 前端新增功能
   - NewGamePage：添加时间选择器（datetime-local），默认为当前时间
   - HistoryPage：添加"编辑"按钮，可跳转到编辑页面
   - 新建 EditGamePage：复用 NewGamePage 逻辑，支持编辑所有字段
   - App.tsx：添加 /edit-game/:id 路由

3. 编辑对局功能
   - 可修改：地点、筹码比率、参与玩家、我的分数、备注、时间
   - 加载现有对局数据并预填充表单
   - 保存后更新数据库记录

4. 用户体验优化
   - 支持补录历史对局（自定义时间）
   - 支持修正错误记录（编辑功能）
   - 编辑页面与新建页面保持一致的交互体验
